# My Text to Speech

Offline neural text-to-speech, powered by [Piper](https://github.com/rhasspy/piper). Includes:

- English and Hindi voices
- Automatic English → Hindi translation ([Argos Translate](https://github.com/argosopentech/argos-translate)) when speaking English text with a Hindi voice
- WAV and MP3 download
- Adjustable speech speed

Everything runs locally in the container — no external API keys or per-request costs.
